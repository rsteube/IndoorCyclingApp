Indoor Bike 1.4

A polish release: the Progress, History, and Settings screens are reworked, and the ride screen gains a few quiet celebration cues. No change to what a ride is worth or how the trainer is driven.

Changed
- **Progress screen comes alive**: your rider level, XP, and weekly streak now animate in on entry - the XP bar fills, the number counts up, and the streak flame breathes. A new badges section shows what you have unlocked, with locked badges hinting at what is next.
- **Redesigned ride history**: each session now leads with a calendar date tile (weekday + day) instead of a date text line, with the workout name and a single compact stats line beside it. Every week group header carries that week's own totals - rides, time, and kilojoules - so you can see how much you did without opening anything.
- **Reorganised Settings**: related fields are grouped into single cards instead of floating as separate boxes, and the "Report a problem" block is now one tappable row with the what-gets-collected detail moved into the confirmation dialog, right before anything is sent.
- **Ride-screen cues**: when you are holding the ERG target the power readout shows a soft "ON TARGET" glow, the screen edges flash once in the new zone's colour as each interval begins, and finishing a workout gets an animated trophy.

Editor (web)
- **Keyboard shortcuts panel**: the in-browser workout editor now lists its shortcuts (select, toggle, range, box-select, duplicate, delete, nudge power/duration) in a togglable panel.
- **Cleaner workout details**: the name and description fields are laid out in a tidier details section.
